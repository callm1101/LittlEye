# 小眼睛 Bilibili 观看提醒扩展

这是一个最小权限的 Manifest V3 扩展，仅在 `bilibili.com` 页面运行，只向本机小眼睛应用发送“页面是否可见且聚焦”和时间戳。它不读取视频标题、播放进度、账户信息、搜索词、页面正文、其他网站 URL 或浏览历史。

## 安装与配对

1. 在 Chrome/Edge 中打开扩展管理页面并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，选择本目录 `browser-extension/`。
3. 在小眼睛桌面端打开“设置 → 哔哩哔哩观看提醒”，阅读隐私说明后启用功能。
4. 复制桌面端显示的配对令牌。
5. 打开扩展的“详情 → 扩展程序选项”，粘贴令牌并选择“保存并测试连接”。

## 卸载

在浏览器扩展管理页面移除此扩展，并在小眼睛设置中关闭“启用浏览器监测”。桌面端的“清除计时”可删除今天累计的本地观看计时。

扩展只连接 `127.0.0.1:47831`，配对令牌保存在浏览器扩展自己的本地存储中。桌面端拒绝非扩展来源、错误令牌、过期时间戳、未知字段和超过大小限制的消息。
