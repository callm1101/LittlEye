# 小眼睛网站浏览提醒扩展

这是一个面向 Chromium 102 及以上版本的最小权限 Manifest V3 扩展。它只在用户明确授权的白名单网站运行，并只向本机小眼睛应用发送“匹配的白名单域名、页面是否可见且聚焦、时间戳”。它不会读取或发送完整网址、标题、账户信息、搜索词、页面正文或浏览历史。

## 安装、配对与网站授权

1. 在 Chrome/Edge 中打开扩展管理页面并启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，选择本目录 `browser-extension/`。
3. 在小眼睛桌面端打开“设置 → 网站浏览提醒”，维护网站白名单并启用功能。
4. 复制桌面端显示的配对令牌。
5. 打开扩展的“详情 → 扩展程序选项”，粘贴令牌并选择“保存并读取白名单”。
6. 核对域名后选择“同步白名单并授权”，在浏览器权限窗口中确认这些网站。
7. 刷新已经打开的白名单网页。此后只有获得授权的域名及其子域名会被计时。

白名单修改后，需要回到扩展选项重新读取并授权。移除的域名会同时撤销扩展网站权限。每个白名单域名单独累计浏览时间，任一域名达到桌面端设置的阈值都会触发提醒。

## 卸载

在浏览器扩展管理页面移除此扩展，并在小眼睛设置中关闭“启用浏览器监测”。桌面端的“清除计时”可删除今天所有白名单域名的本地浏览计时。

扩展只连接 `127.0.0.1:47831`，配对令牌和已授权域名保存在浏览器扩展自己的本地存储中。桌面端拒绝非扩展来源、错误令牌、白名单外域名、过期时间戳、未知字段和超过大小限制的消息。
